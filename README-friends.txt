EMBRIS - key & click macro for Roblox
=====================================

How to install
1. Unzip this folder (right-click the zip > Extract All).
2. Double-click EmbrisSetup.exe and click Install.
   - No admin needed. It installs just for you.
   - It adds Embris to the Start menu (and your desktop if you leave that on).

"Windows protected your PC"?
   The app isn't signed by a big company, so Windows warns about it.
   Click "More info", then "Run anyway".

How to use
- Macro page: pick Roblox as the target app and "Switch to it briefly" as the send mode.
- Press F6 anywhere to start or stop (you can change the key on the Hotkeys page).
- Record: click Record (or press F8), do your moves in Roblox, press F8 again to stop.
- Sequence editor / Timeline editor: edit what you recorded (move, stretch, cut, crop).
- Auto clicker page: simple clicking at any speed, with its own hotkey (F7).
- Presets page: save setups, give each its own hotkey, or build a macro step by step.
- Already have Embris? Run EmbrisSetup.exe again and click Update.

How to uninstall
   Windows Settings > Apps > Installed apps > Embris > Uninstall.
